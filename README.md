# Timeglass Claude Code marketplace

This repository holds the Timeglass plugin for Claude Code. The plugin connects Claude Code to Timeglass so you can ask about your recorded work, meetings and timesheets, and make edits your Timeglass role allows. Add the marketplace and install it:

```
/plugin marketplace add Palsson-Weston/timeglass-claude-plugins
/plugin install timeglass@timeglass
```

See [plugins/timeglass/README.md](plugins/timeglass/README.md) for setup and the list of skills.
